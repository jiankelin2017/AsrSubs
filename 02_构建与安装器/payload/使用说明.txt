AsrSubs 使用说明
 v1.2.5
在 DaVinci Resolve 里离线自动生成字幕，音频不上传。
三步上手
打开：Resolve → 工作区 → 脚本 → AsrSubs → AsrSubs
菜单里没有就完全退出 Resolve 再开。
生成字幕：选语言、每行字数（中文建议 20~32）→ 点【开始生成】。
单片段、速度 1：直接读源文件，快。
多片段或变速：先导出音频再识别，慢但声画对齐。
按钮是灰的 = 条件不满足（没开时间线 / 时间线没片段 / 环境自检没过 / 上一轮还在跑），补齐后 3 秒内自动变亮。
适配字幕：点【适配字幕】，字幕挂到当前时间线的字幕轨，原视频/音频不动。
同时导入媒体池，保存到 data\output\。
素材旁也会放一份同名 .srt（可在设置里关掉）。
改字幕
改字：单击表格任意行，在下方编辑框直接打字。
查找：查找框输入即定位，命中行亮琥珀色，播放头停手 0.2 秒后跳过去；小【▶】= 下一处。
多选：Ctrl 加选 / Shift 连选，或【全选】【反选】；【删除】删选中行（有确认）。
删词：查找框填词、替换框留空 →【全部替换】，可清"嗯、啊、那个"。
替换：【替换】只改当前行，【全部替换】改所有命中行。
撤销：状态条右侧【撤销】，只有一级。
写回：【字幕更新】是唯一写文件入口。状态条显示「SRT 有改动」= 未写回，「已写回 SRT」= 已落盘。
切掉删掉的视频（粗剪）
先删字幕行。
点【字幕更新】，等状态条变「已写回 SRT」。
状态条出现「· 将切除 3 段 · 12.4s」时，点【视频粗剪】。
确认框会写清代价；不满意按 Ctrl+Z 一次退回。
注意：必须先把 SRT 写回才能粗剪；切口前后各留 0.10 秒气口；间隔小于 0.30 秒的相邻段会合并。
其它功能
权重词纠错：左边正确词，右边错误写法（逗号隔开），如 人参=人生,人叁，识别完自动替换。
断点续跑：同素材再识别会复用上次分段，只补没跑完的。
热词：窗口底部自动统计高频名词/动词/形容词，写错的选中复制到纠错表。
换模型：下拉框选，或把模型文件夹放进 models\，或填自定义路径。1.7B 需更多显存，8G 显卡可能跑不动。
诊断信息：点顶部「AsrSubs v1.2.5」版本号查看；出错时「设置」按钮会带 ⚠。
出问题先看这里
前提：首选项 → 系统 → 常规 → 外部脚本使用 → 设为「本地」或「网络」。
现象	处理
菜单里没有 AsrSubs	完全退出 Resolve 后重开
读取时间线失败	检查「外部脚本使用」设置
适配字幕点不动	表格空 = 还没识别成功，点【开始生成】重来；有字幕但按钮灰 = 关插件重开
识别很慢	状态栏写「CPU 模式」= 没用显卡，重跑安装器选 GPU 版
视频粗剪是灰的	没删过行 / SRT 没写回 / 有任务在跑，状态栏会说明
字幕比 SRT 少几条	Resolve 会合并过短/同帧/重叠条目，调大「每行字数」可减少
热词那行空着	缺 jieba，执行 runtime\Scripts\python.exe -m pip install jieba 后重开插件
进度条不动/报错	点版本号看诊断，或看 data\logs\AsrSubs_error.log
第一次点【开始生成】可能闪一下命令行窗口（启动后台执行器），之后不会再有。
新电脑安装
双击《AsrSubs安装器.exe》→ 选位置 → 两次「下一步」→ 自动下载运行环境和模型（3.4~6 GB）。
有 NVIDIA 显卡默认选 GPU 版（快数倍，多下载约 2.5 GB）；没有则默认 CPU 版。
默认装到 D:\AsrSubs，路径只能英文/数字，不能有中文，只能装本地硬盘。
装完 DaVinci 菜单里就有，没有就重启。
卸载：开始菜单「AsrSubs → 卸载 AsrSubs」或 Windows「设置 → 应用」。会问是否连字幕产物一起删（默认保留，且卸载前自动备份到「文档」）。卸载前先退出 Resolve。
