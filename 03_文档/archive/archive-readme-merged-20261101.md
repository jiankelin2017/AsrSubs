## 发布流程（严格按序）

```bat
:: 1) 改完代码后，先同步到 engine（否则 --deploy 的回灌会覆盖你的改动）
copy 01_源码\*.lua  D:\AsrSubs\engine\
copy 01_源码\*.py   D:\AsrSubs\engine\

:: 2) 升版本
编辑 01_源码\version.txt  →  python 01_源码\tools\sync_version.py

:: 3) 推 payload + 部署
python 01_源码\tools\sync_payload.py
python sync_dev.py --deploy

:: 4) 验收
python 01_源码\tools\verify_all.py            :: 期望 16/16
python 01_源码\tools\check_live_readonly.py   :: 真机只读巡检

:: 5) 出包（在 01_源码 下）
::    02_构建与安装器\build.bat → dist\AsrSubs安装器.exe
::    改名带版本号后拷进 04_安装包\（细节见 04_安装包\README_说明.txt）
```

> `sync_dev.py` 的 `HERE` 自动取脚本所在目录：
> `PAYLOAD` → `02_构建与安装器\payload`，`DOC` → `03_文档`。
> 从本目录直接跑 `python sync_dev.py` 显示三项全"一致"。
