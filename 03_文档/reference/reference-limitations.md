# 参考 · 已知限制与未完成项

## 一句话摘要

当前版本**仍然成立**的限制与尚未做完的事项；已完成项和验收流水账不在此页。

## 当前有效结论

### 产品限制（用户可感知）

| 限制 | 说明 | 来源 |
|---|---|---|
| 安装包本体约 12 MB，运行环境与模型装完**在线下载**（3.4~6 GB） | 断网机器只能先备好 `engine` + `models` 再手工部署 | 旧 README §6 |
| 跨窗上下文已关闭（`CTX_CHARS = 0`） | 人名 / 数字在不同窗口的写法可能不一致 | 旧 README §6 |
| 热词统计依赖 jieba（在 `runtime` 里） | 缺失时整行留空，不影响出字幕 | 旧 README §6 |
| 表格只能**整格染色** | Tree 单元格不支持富文本，词级高亮只在编辑区生效 | 旧 README §6 |
| 选中行会盖住命中底色 | Qt 用系统高亮色重绘选中行，这是刻意的优先级 | 旧 README §6 |
| **撤销只有一级** | 切除视频后的撤销走「重建时间线」，不是回滚字幕 | 旧 README §6、开发文档 §9 |
| **粗剪不保留效果** | 重建出的片段不带转场 / Fusion 特效 / 调色节点 | 旧 README §6、开发文档 §9 |
| `App:FindPrev` 已无 UI 入口（v3.1.3 删掉「◀」按钮） | 目前是死代码 | 旧 README §6 |
| 卸载前须退出 DaVinci Resolve | 否则文件被占用会删不掉 | `04_安装包\README_说明.txt` |
